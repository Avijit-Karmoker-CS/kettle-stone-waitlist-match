Put the clinic's files in this folder:

  waitlist....csv        the typed waitlist (Tanya's notebook). The newest one is used.
  appointments-....csv   the Kneadly booking exports. KEEP THE OLDER ONES TOO:
                         the program reads them all together, so it still knows
                         who got a spot weeks ago.
  late-openings-....csv  optional: a list of openings to match all at once (newest used).

CSV is best. Numbers files also work. Excel files must be saved as CSV.
The program window notices new files by itself within a few seconds.
The program keeps its own records in 'logs' and a daily copy of the
waitlist in 'backups'. This folder holds health details: keep it on this
computer only, inside the clinic's normal backup.
