Put the clinic's files in this folder:

  waitlist.csv          the typed waitlist (Tanya's notebook). Keep adding to the end.
  appointments-....csv  the Kneadly booking export Julie saves each week (or each day,
                        once the daily report is on). The newest one is used.
  late-openings-....csv optional: a list of openings to match all at once.

CSV is best. Numbers files also work. Excel files must be saved as CSV.
The program keeps its own records in the 'logs' folder and a daily copy
of the waitlist in 'backups'. This folder holds health details: keep it
on this computer only, inside the clinic's normal backup.
